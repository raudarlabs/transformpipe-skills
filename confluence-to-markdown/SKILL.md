# Confluence space to Markdown

TransformPipe converts the HTML export of a Confluence space into Markdown. It runs in the browser
at https://transformpipe.com/confluence-to-markdown and is free and open source (MIT). Nothing is
uploaded unless the user signs in and saves.

The agent cannot do the export or the upload itself: a Confluence export and a browser upload are
the user's steps. The agent's job is to guide them, then work with the Markdown that comes out.

## 1. Export the space from Confluence

Walk the user through it:

1. Open the space, then **Space settings** → **Export space** (on older versions:
   **Space tools** → **Content tools** → **Export**).
2. Choose **HTML**, then **Normal export** for the whole space, or **Custom export** for part of it.
3. Download the `.zip`. Do not unpack it.

Exporting needs the "Export space" permission. If the option is missing, the user has to ask a
space admin.

## 2. Convert it

1. Open https://transformpipe.com/confluence-to-markdown and drop the `.zip`. Up to 250 MB works.
2. By default the space becomes a **folder of pages**:
   - one Markdown file per page;
   - a subfolder per section, with the section's own page first inside it;
   - links between pages pointing at the other files;
   - contents macros pointing at heading slugs.
3. Pick one of two outputs:
   - **Download** a `.zip` of Markdown files in the same tree. It comes in a flavour for GitHub and
     editors, or one for Obsidian, whose heading links are spelled differently.
   - **Save** to a TransformPipe account. Each page becomes a document in a folder, searchable and
     shareable, and reachable from the agent through the TransformPipe MCP connector
     (`tp_list_documents` with `folder`).
4. **One document** instead joins every page into a single file under a contents list. This is
   better for feeding the whole space to a model than for browsing.

## 3. Check the result

Tell the user what does not come across, so nothing surprises them later:

- **Macros:** they arrive as the HTML Confluence rendered. An info panel becomes plain paragraphs.
- **Merged table cells:** the text lands in the first cell. A cell holding a list or several
  paragraphs is flattened onto one line.
- **Non-picture attachments:** PDFs and other files are not carried, and their links become their
  names.
- **Pictures:**
  - They are embedded in the page, scaled down to at most 1,600 px.
  - Each page carries up to about 4 MB of them, and none over 1 MB.
  - A picture past that limit becomes its description in italics.
- **Page frame:** the space-name heading, author line and "Document generated by Confluence" may
  remain. Remove them with a search and replace if needed.
- **Code:** it becomes a fenced block only where the HTML had `<pre><code>`.

After a download, open a few pages with tables, code and pictures, and follow some links between
pages before deleting anything in Confluence.

## For scripts

`POST https://transformpipe.com/api/v1/documents?kind=confluence-to-markdown` takes the `.zip` as
the request body, with an API key from the account menu as `Authorization: Bearer tp_live_…`.

- One request carries at most 4 MB, so the browser is the way to convert a large space.
- Reference: https://transformpipe.com/docs
